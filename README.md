# java-wordle4j — готовая реализация

Реализация задания Wordle по предоставленному ТЗ.

Возможности:
- загрузка словаря UTF-8 через BufferedReader и try-with-resources;
- нормализация слов: нижний регистр и замена ё на е;
- проверка пятибуквенных русских слов;
- корректный алгоритм Wordle с повторяющимися буквами;
- 6 попыток;
- случайное загаданное слово;
- случайные подсказки среди подходящих слов;
- исключение уже использованных слов из подсказок;
- логирование через PrintWriter;
- JUnit 5 тесты.

По умолчанию программа ищет словарь `dictionary.txt` в корне проекта.
Путь к словарю можно передать первым аргументом программы.

Для тестов можно передавать `new Random(0)`, чтобы случайность была воспроизводимой.
Для обычной игры используется `new Random()`.
